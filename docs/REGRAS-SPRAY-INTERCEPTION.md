# Regras de Uso — SPRAY INTERCEPTION

> Versão 1.0 — agosto/2026

Ao instalar ou usar o SPRAY INTERCEPTION, você concorda com os termos abaixo.

---

## 1. O que é o software

Ferramenta de **treino** de compensação de recoil para Windows. O app:

- **Não** lê memória do jogo
- **Não** injeta código no processo do jogo
- **Não** modifica arquivos do jogo
- **Não** se comunica com o jogo

Move o mouse via driver de input (Interception), com parâmetros configuráveis pelo usuário.

## 2. Uso permitido

Indicado para:

- Single-player e campanhas
- PvE e cooperativo
- Servidores privados onde macros são permitidos
- Treino offline e criação de conteúdo
- Acessibilidade

## 3. Uso de risco

Em jogos online competitivos (Vanguard, BattlEye, Easy Anti-Cheat, Ricochet etc.) o uso **pode violar** os Termos de Serviço do jogo e causar **banimento permanente**.

**Não garantimos:**

- Indetectabilidade por anti-cheat
- Funcionamento em todos os jogos
- Que sua conta não será banida

**Você assume total responsabilidade** por banimentos, perda de conta, itens ou progresso.

## 4. Requisitos

- Windows 10 ou 11 (64 bits)
- Executar como Administrador
- Driver Interception (instalado pelo setup)
- Conta no app (email + senha)

## 6. Driver Interception

O app instala o driver Interception (filtro de input no kernel). Você entende que:

- Pode ser detectado por anti-cheat ou software de segurança
- Pode ser desinstalado com `install-interception.exe /uninstall` (requer reboot)
